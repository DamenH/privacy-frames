# Single origin host and GitHub Pages migration

- [ ] Compact dark interface: URL, Install, app list, Open/Remove, example links and optional diagnostics/report.
- [ ] One static host origin with direct authenticated management, no iframe bridge and no separate runtime deployment.
- [ ] Test protection of host data, worker management and manager windows on the shared origin; retain context/network/compatibility/failure tests.
- [ ] Host source in DamenH/privacy-frames; independent applications in DamenH/privacy-frames-apps, on a distinct publisher origin.
- [ ] GitHub Pages builds and deployed tests; update existing share link without rotation.
- [ ] Accurate report, evidence and reproduction instructions.

The earlier package-only installation convention remains in this implementation. Network-enabled explicit installation callbacks are a separate discussed direction, not silently added to this UI/deployment migration.
